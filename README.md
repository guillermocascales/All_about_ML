# All about ML

This repository contains basic implementations on Python of classic theoretical concepts of Machine Learning, with help of known libraries such as 
Tensorflow, Numpy or Matplotlib. The notebooks were all developed during the course in Mathematics of Machine Learning done in Universität Ulm, where
I learned about all of this concepts.

This repository is still being developed. I am planning on uploading content on concepts that I find interesting, such as dimensionality reduction (PCA)
for the mathematical side, or some useful workflows used in data processing.
